# Sovushka

Sovushka is a 2D game developed using Unity and C#. The project features interactive gameplay, player movement, enemy encounters, collectible mechanics and a custom audio system.

## Overview

The game is designed for landscape-oriented mobile gameplay, with an interface optimized for touchscreen controls.

## Features

- 2D player movement and controls.
- Touchscreen-based mobile input.
- Enemy encounters and gameplay interactions.
- Collectible system.
- In-game HUD and UI elements.
- Centralized audio management and sound effects.
- Android landscape support.

## Getting Started

### Requirements

- Unity Hub
- Compatible Unity Editor version
- Android Build Support (for Android builds)

### Setup

1. Clone this repository.
2. Open Unity Hub.
3. Select Add Project from Disk.
4. Navigate to the cloned project directory.
5. Open the project using the compatible Unity Editor version.
6. Open the main scene and run the game.
